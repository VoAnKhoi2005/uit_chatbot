## 🎯 System Overview

You now have **two** BM25 RAG systems:

### 1. **Baseline System** (bm25_rag.py + evaluate.py)
- ✅ No API key needed
- ✅ Very fast (2 seconds for 500 questions)
- ❌ Simple answer: just concatenates documents
- 💰 **FREE**

### 2. **LLM-Enhanced System** (bm25_llm.py + batch_api.py)
- ⚠️ Requires OpenAI API key
- ⏱️ Slower (10-30 minutes for 500 questions)
- ✅ Natural language answers from GPT-4o-mini
- ✅ Better formatting and context understanding
- 💰 **~$0.05-0.10 for 500 questions** (with Batch API 50% discount)

### Option 3: LLM Batch Processing (All 500 Questions)

⚠️ **This will cost ~$0.05-0.10 USD**

#### Method A: Fully Automated (Recommended)

```cmd
python batch_api.py --action full --wait
```

**What happens:**
1. ✅ Creates batch input file with all questions + retrieved contexts
2. ✅ Uploads to OpenAI Batch API
3. ✅ Waits for completion (checks every 60 seconds)
4. ✅ Downloads results automatically
5. ✅ Generates final CSV: `bm25_llm_results.csv`

**Expected timeline:**
- Step 1 (Create): ~30 seconds
- Step 2 (Upload): ~10 seconds
- Step 3 (Wait): **10-30 minutes** (OpenAI processing)
- Step 4-5: ~10 seconds

└── batch_output.jsonl        ← Batch API output (if you ran batch)

### CSV Structure

Both CSV files contain:

| Column | Description | Example |
|--------|-------------|---------|
| question | Original question | "Người học bồi dưỡng..." |
| extractive_answer | Ground truth (extractive) | "a) Được cấp sau khi..." |
| abstractive_answer | Ground truth (abstractive) | "Việc cấp chứng chỉ..." |
| **predicted_answer** | **System's answer** | **Baseline**: Raw documents<br>**LLM**: Natural language |
| question_type | Question category | EXACT_RULE, NEAR_RULE, OUT_OF_SCOPE, ERROR |

## 🔧 Troubleshooting

### Issue 1: "OPENAI_API_KEY is required"

**Cause:** API key not set

**Solution:**
1. Create `.env` file with your API key:
   ```
   OPENAI_API_KEY=sk-your-key-here
   ```
2. Or set environment variable:
   ```cmd
   set OPENAI_API_KEY=sk-your-key-here
   ```

### Issue 2: "ModuleNotFoundError: No module named 'openai'"

**Cause:** Dependencies not installed

**Solution:**
```cmd
pip install -r requirements.txt
```

### Issue 3: Batch still processing after 30 minutes

**Cause:** OpenAI queue might be busy

**Solution:**
- This is normal! Can take up to a few hours during peak times
- Check status periodically:
  ```cmd
  python batch_api.py --action status --batch-id YOUR_BATCH_ID
  ```
- Or leave it and come back later

### Issue 4: "sqlite3.OperationalError: unable to open database file"

**Cause:** Database path is wrong

**Solution:**
- Verify database exists:
  ```cmd
  dir E:\Github\uit_chatbot\normailizer\uit_law_points.db
  ```
- If not, check the correct path

### Issue 5: Batch failed

**Cause:** API error or malformed request

**Solution:**
1. Check error details:
   ```cmd
   python batch_api.py --action status --batch-id YOUR_BATCH_ID
   ```
2. Common fixes:
   - Verify API key is valid
   - Check you have credits in OpenAI account
   - Recreate batch input file
